# To-Do List App ✅

## 🔹 Description
A simple and interactive To-Do List application that allows users to **add, complete, and manage daily tasks**.  
Built using JavaScript to practice **DOM manipulation and dynamic UI updates**.

---

## 🔹 Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface
- Real-time task updates

---

## 🔹 Tech Stack
- HTML
- CSS
- JavaScript
